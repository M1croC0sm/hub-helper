Install or update

One-time change for version 0.11.1 and older: this download starts a new signing baseline. Export a backup from the old app first, then uninstall it, install this version, and import your backup. Uninstalling removes data still stored in the old app. Future versions from this page will install as updates.

If you received version 0.12.0 directly from the maintainer on September 26, you already have the new baseline and do not need to reinstall.

  1. Tap Download / update Hub Helper to get the latest APK.
  2. Allow installation from your browser or file manager if Android asks.
  3. If Hub Helper is already installed, choose Update. Your records and settings stay on your phone. New users can complete setup after installing.

Bookmark this page. The same address always offers the latest published build. In Hub Helper, open Settings → Share Hub Helper → Open download page to return here.

Updates are installed by you; the app does not check the Internet or download updates in the background. Export a backup in Settings before updating. After the one-time transition above, do not uninstall the app to update it.

If Android reports a package conflict, keep the installed app and contact the maintainer. Builds signed with a different key cannot update each other.
