# Contributing

Thank you for helping improve Hubb Helper.

1. Do not submit employee names, IDs, attendance sheets, medical details, internal documents, credentials, signing keys, or other confidential data.
2. Open an issue before a large behavioral or policy-calculation change.
3. Create a focused branch and include tests for calculation or parser changes.
4. Run `./gradlew test lintDebug assembleDebug` before requesting review.
5. Identify assumptions and cite an authorized source for policy rules.
6. Preserve the no-Internet, local-first design unless a separately reviewed proposal explicitly changes that architecture.

Contributions are submitted under the repository's software license. Reference content is excluded unless the contributor documents permission to redistribute it.
